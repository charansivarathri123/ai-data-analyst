Build a complete, production-quality Data Visualization & Dashboard module for a Data Analyst application.
The purpose of this module is to transform analyzed data into clear, interactive, accurate, and business-ready visualizations.
The module must support automatic chart recommendations, manual chart creation, interactive filtering, dashboard creation, KPI cards, drill-downs, exports, and AI-assisted insight generation.
Do not create a simple chart demo. Build a professional Data Analyst visualization system.
